# Criando com Claude Code

Página de fila de espera do curso **Criando com Claude Code (do zero ao resultado)**, de Ezequiel Costa.

Quem acessa a página conhece o conteúdo do curso e entra na comunidade do WhatsApp para receber o aviso quando as inscrições abrirem.

## Arquivos

- `index.html`: a página completa, em um único arquivo (HTML, CSS e JavaScript juntos). As fontes vêm do Google Fonts.

## Publicar

Por ser um site estático, pode ser publicado direto deste repositório:

- **Cloudflare Pages**: conecte o repositório, deixe o comando de build vazio e use `/` como diretório de saída.
- **GitHub Pages**: em Settings › Pages, escolha a branch `main` e a pasta `/ (root)`.
